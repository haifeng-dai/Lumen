Lumen 专为追求极致流畅、轻量专注的科研人员设计。

我们拒绝了 Electron 等动态运行时的臃肿包袱，基于 **Rust** 语言与 **GPUI** 框架（由 Zed 编辑器团队开发的高性能全 GPU 加速 UI 框架）从底层构建，致力于带来**极速、轻量与专注**的科研阅读与文献管理体验。

---

## 核心特性

### GPU 硬件加速原生 PDF 阅读引擎

- **硬件光栅化渲染：** 基于底层 GPU 硬件加速的高性能原生渲染管线，提供 60+ FPS 的超流畅连续滚动、自由缩放与瞬时翻页体验。
- **深度文档交互：** 支持顺滑跨页文本选择、毫秒级高精度全文搜索与结果跳转、丰富的多色高亮与划线标注。
- **层级化导航体系：** 目录大纲树结构、带文本预览的可视化同步缩略图栏、快速书签跳转。

### 画中画（PiP）文献悬浮比对

- **自由图表钉选：** 支持将文献中的图表、表格、核心公式或关键整页一键钉选为置顶画中画浮窗，阅读后文时无需来回翻动寻找上下文。
- **硬件级平滑缩放与多级精细重绘：** 悬浮窗支持自由拖拽、无级尺寸调节与 GPU 硬件平滑拉伸，松手后自动按量化精度进行后台高清重绘，兼顾操作流畅与文字锐利度。
- **跨位置对照阅读：** 方便在研读模型设计、实验结果或定理推导时，始终将系统架构图或前置定义固定在可视区域。

### AI 学术助手与文献分析

- **上下文感知对话：** 深度结合当前论文全文上下文的多轮对话助手，支持自定义系统提示词与历史提问回滚。
- **智能分析与笔记自动生成：** 一键生成论文摘要、核心贡献剖析与实验总结，直接保存至文献专属笔记库。
- **多会话独立管理：** 单篇文献支持创建并保留多个独立 AI 对话分支，便于从不同研究视角深入探讨。

### 文献与引文管理

- **元数据自动化抓取：** 支持拖入本地 PDF 自动提取，或通过 DOI、ArXiv ID 快速联网解析补全详尽的著录信息。
- **多层级分类组织：** 无限层级文件夹树、灵活的多标签管理、阅读状态标记与跨库全文检索。
- **论文写作格式导出：** 规范化引文导出，完整支持 BibTeX（`.bib`）、IEEE、Elsevier 及 APA 等学术期刊格式。

### 全平台云端同步体系

- **分离式同步架构：** 附件文件与关系型元数据解耦独立同步，大幅提升同步效率。
- **WebDAV 附件云存储：** 自由绑定私有 WebDAV 节点或商业云盘（坚果云、InfiniCLOUD、Nextcloud 等），安全同步 PDF 原文。
- **关系型一致性同步引擎：** 采用多端关系型数据同步架构与确定性冲突消解策略，确保多设备间的数据强一致性。

### 沉浸式翻译与纯原生跨平台

- **工作流内即时翻译：** 划词与段落即时翻译直接嵌入阅读工作流，无缝支持多语言文献研读。
- **纯原生全平台分发：** 摆脱 Chromium/Node.js 庞大依赖，超小体积、极速启动，覆盖 Windows（x64）、macOS（Apple Silicon / Intel）及 Linux（Debian/Ubuntu）。

## 设计理念

- **零感知延迟：** 纯原生编译结合 GPU 光栅化渲染，保证在翻页、缩放与切换文献时零迟滞。
- **极低资源占用：** 告别冗余的内存消耗，以极低的系统开销常驻后台。
- **克制与专注：** 简洁干净的现代化交互，剔除一切干扰元素，让注意力回归阅读与思考本身。

## 已知问题

- **macOS PDF 渲染内存释放问题：** 受限于上游 GPUI 框架在 macOS 平台下对图片与 GPU 纹理缓存的内存管理和释放机制，PDF 页面光栅化渲染所占用的内存在关闭文档后可能无法被系统立即完全回收，在长时间连续阅读多篇大型文档时可能出现内存占用偏高现象。目前正在持续跟进上游进展并优化应用层的缓存淘汰与释放策略。
